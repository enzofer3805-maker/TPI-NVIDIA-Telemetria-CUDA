# TPI - Organización Empresarial

## Empresa seleccionada
NVIDIA Corporation

## Proyecto
Sistema de Telemetría y Facturación Dinámica para CUDA

## Objetivo
Desarrollar una solución que permita registrar métricas de consumo de recursos CUDA, procesar la información obtenida y generar procesos automáticos de facturación para los clientes de NVIDIA.
