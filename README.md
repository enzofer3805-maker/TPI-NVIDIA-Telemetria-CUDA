# TPI - Organización Empresarial

## Empresa seleccionada
NVIDIA Corporation

## Proyecto
Sistema de Telemetría y Facturación Dinámica para CUDA

## Objetivo
Desarrollar una solución que permita registrar métricas de consumo de recursos CUDA, procesar la información obtenida y generar procesos automáticos de facturación para los clientes de NVIDIA.

## Integrantes
Enzo Fernández

## Herramientas utilizadas
- BPMN (Bizagi)
- Git
- GitHub
- GitHub Projects
## Estado del Proyecto

Trabajo Práctico Integrador correspondiente a la asignatura Organización Empresarial.

## Declaración de Transparencia en el Uso de Inteligencia Artificial

Durante la realización del Trabajo Práctico Integrador "Sistema de Telemetría y Facturación Dinámica para CUDA de NVIDIA" se utilizó Microsoft Copilot como herramienta de asistencia para la elaboración y revisión de contenidos académicos.

### Usos realizados

La herramienta fue utilizada para:

- Revisar la redacción y organización general de los informes.
- Generar propuestas de mejora para la documentación del proyecto.
- Brindar apoyo en la documentación relacionada con Git, GitHub, Pull Requests y GitHub Projects.
- Revisar aspectos conceptuales del modelado BPMN y su adecuación a la notación estudiada en la materia.

### Ejemplos de prompts utilizados

- "Proponer indicadores KPI para un sistema de telemetría y facturación basado en CUDA."
- "Revisar la estructura de un BPMN para un proceso de facturación."
- "Explicar cómo documentar un proyecto académico en GitHub."

### Correcciones y adaptaciones realizadas manualmente

Todas las respuestas obtenidas fueron revisadas y validadas antes de ser incorporadas al trabajo.

Las principales intervenciones realizadas por el autor fueron:

- Adaptación de los contenidos a las consignas específicas de la cátedra.
- Corrección manual del modelo BPMN según la devolución recibida.
- Selección y organización de capturas de GitHub, commits, ramas y Pull Requests.
- Integración de las entregas 1, 2, 3 y 4 en un único documento.
- Ajuste de indicadores KPI al caso de estudio seleccionado.
- Revisión de consistencia conceptual entre TGS, Sistemas de Información, Procesos, BPMN y Gestión Ágil.

La responsabilidad sobre la veracidad, coherencia y calidad académica del contenido final corresponde exclusivamente al autor.
